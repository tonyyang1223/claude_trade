# Bittensor (TAO) 估值建模与竞品对比笔记

> 用途：最终投研报告素材，非交付物。整理时间：2026-10-08。
> 基准价：TAO ≈ $300（区间 $288–$313 取中值），MC $3.4B，FDV $6.4B，流通 11.34M / 上限 21M（流通率 54%）。
> 数据来源：`_raw_hard_data_20261008.json`、`_research_raw_bittensor_history.md`，竞品缺口由 CoinGecko/CoinCodex/CryptoSlate/Bybit/MarketBeat 2026-10-04~08 快照补齐。

## 一、估值锚点推导

### 1.1 历史 FDV 分位
- ATH $776（2024-04-11），对应 FDV = 776 × 21M = **$16.3B**；当时流通约 6–7M，对应 MC ≈ $5.0B。
- ATL $30.25（2023-05-14），对应 FDV = 30.25 × 21M = **$0.64B**。
- 当前 FDV $6.4B，占 ATH FDV 的 6.4 / 16.3 = **39.3%**；落在历史 FDV 区间 (0.64, 16.3) 的 (6.4−0.64)/(16.3−0.64) = **36.8% 分位**。
- 即：按 FDV 口径，TAO 现在处于历史中下部，但远未到 ATL 附近的"地板价"。

### 1.2 流通率与稀释（3 年视角）
- 2025-12-12 首次 halving 后日发行 3,600 TAO；年释放 = 3,600 × 365 / 1e6 = **1.314M TAO/年**。
- 3 年后流通量 = 11.34 + 1.314 × 3 = **15.28M**；流通率 = 15.28 / 21 = **72.8%**。
- 下一次 halving 触发线为累计 15.75M；剩余额度 = 15.75 − 11.34 = 4.41M，按 1.314M/年需 3.36 年，故 3 年窗口内不再减半，上述释放速度成立。
- **MC 不变（$3.4B）时的 3 年目标价** = 3.4B / 15.28M = **$222.5**（即稀释 alone 带来 −26%）。
- **要在 3 年后维持 $300 价格**，需 MC 扩张到 15.28 × 300 = **$4.58B**（较当前 +35%）。
- FDV 口径下价格与流通量无关（FDV = 价格 × 21M 上限），"FDV 不变"即价格不变；稀释只压缩 MC。

### 1.3 竞品横向 FDV 排序（AI 叙事赛道）
FDV 排名（单位 $B）：**TAO 6.4 > WLD 5.5 > RENDER 1.0 > FET/ASI 0.67 > AKT 0.30 > IO 0.13 > AGIX 0.05**。
- TAO 是赛道内 FDV 最大的标的，比第二名 WLD 还高 16%，是 RENDER 的 6.4 倍。
- TAO FDV/MC = 6.4 / 3.4 = **1.88**，仅低于 WLD 的 3.67（WLD 低流通率 38.4% 造成的解锁压力），高于 RENDER 1.00、FET 1.20、AKT 1.30、IO 1.64。
- 距 ATH 回撤：TAO −61%，其余竞品 −89% ~ −97.5%。**TAO 是赛道内回撤最浅、相对溢价最高的标的**。

### 1.4 协议收入 / P-S
- Bittensor 协议本身**不收 gas、不抽成**，价值捕获靠 emission 分配 + dTAO AMM 买压间接传导。
- 外部 Subnet 已知 ARR：Targon ≈ $10.4M、Vanta ≈ $0.58M/年（$48K/月）、SCORE 企业合同（PwC/AVIA/Reading FC，金额未披露）。合并口径粗估生态年收入 **$12–15M**。
- 即使乐观假设协议层能捕获 20%（实际无抽成机制），对应收入 $2.4–3.0M；对 MC $3.4B 的 P-S ≈ **1,100–1,400x**。
- 对比：RENDER 走 BME（渲染费直接销毁 RENDER，通缩），AKT 走部署支出池税（2026-03 BME 激活）——二者价值捕获路径直接可见，TAO 完全靠叙事 + emission 稀缺。

### 1.5 机构化溢价
- Grayscale GTAO Trust 2025-12-30 递交 S-1 申请 NYSE Arca 上市，截至 2026-10 待批；当前 OTCQX AUM 仅 $9–12M。
- 参照 IBIT 2024-01-11 上市后 BTC 在 2 个月内从 ~$46K 升至 ~$73K（+59%），给机构化情景一个 **1.2–1.4x FDV 溢价系数**。
- Polychain 累计 $200M 仓位、DCG Yuma 子公司、Coinbase 2025-02 上线，构成"准合规通道"管线。

## 二、三档估值区间

### 悲观情景：$150 – $200
核心假设：AI 叙事退潮、GTAO S-1 再被拖 12 个月以上、再现一起 subnet owner 钱包/供应链事件、市场认清"无协议抽成"硬伤。
- 目标 FDV = $3.15B – $4.20B（= ATH FDV 的 19% – 26%）。
- 目标价 = 3.15B / 21M = **$150**；4.20B / 21M = **$200**。
- 对应 MC（按当前流通 11.34M）= 11.34 × 150 = **$1.70B**；11.34 × 200 = **$2.27B**。
- 较当前 $300：**−50% 到 −33%**。
- 3 年后验证：若届时流通 15.28M，$175 中枢对应 MC = $2.67B，仍高于 ATL 时代水平。

### 中性情景：$380 – $520
核心假设：GTAO 6–12 个月内在 NYSE Arca 获批，机构资金缓慢流入（GTAO AUM 增至 $50–100M，相对 MC 量级小但情绪催化强）；subnet ARR 两年内从 $12M 增至 $30–40M；无重大安全事件；PoA→PoS 无明确时间表但无丑闻。
- 目标 FDV = $8.0B – $10.9B（= ATH FDV 的 49% – 67%，含 ~1.2x 机构化溢价）。
- 目标价 = 8.0B / 21M = **$380**；10.9B / 21M = **$520**。
- 对应 MC = 11.34 × 380 = **$4.31B**；11.34 × 520 = **$5.90B**。
- 较当前 $300：**+27% 到 +73%**。
- 3 年视角：$450 中枢 × 15.28M = MC $6.88B（3 年 2.0x，CAGR ≈ 26%）。

### 乐观情景：$750 – $950
核心假设：GTAO 获批并复制 IBIT 式"批准行情"（FDV 1.3–1.5x）；AI 叙事进入下一轮主升；subnet 收入复合增长到 $100M+ ARR 并出现显性协议费捕获机制；TAO 被机构列为"AI 蓝筹"与 ETH/SOL 并列。
- 目标 FDV = $15.8B – $20.0B（= ATH FDV 的 97% – 123%）。
- 目标价 = 15.8B / 21M = **$750**；20.0B / 21M = **$950**。
- 对应 MC = 11.34 × 750 = **$8.51B**；11.34 × 950 = **$10.77B**。
- 较当前 $300：**+150% 到 +217%**。
- 注意：要在 3 年后（流通 15.28M）站稳 $950，MC 需达 $14.5B（当前 4.3x），必须同时具备"机构买盘 + AI 周期 + 收入兑现"三要素，缺一则落入中性区间上沿。

## 四、关键风险点

1. **中心化与治理**：链仍为 PoA（Aura+GRANDPA）+ OTF sudo key，PoS 转型无时间表；中位 subnet 单 coldkey 占 57% 质押（2026-09-18）。
2. **安全事件频出**：2024-07 PyPI 假冒包窃 32,000 TAO（~$8M）；2026-03 bittensor-wallet v4.0.2 后门；2026-07-13 同日 SN15/SN102 owner 钱包被 drain（合计 ~$80 万）。攻击面在工具/钱包层而非协议层，但反复磨损信任。
3. **稀释与解锁**：仍有 46% 上限未发行；即便 halving 后，每年仍新增 1.31M TAO（年化通胀 6.2%）。
4. **监管不确定**：GTAO S-1 审批时点不可控；SEC 对 AI 类代币的执法边界、EU MiCA 对 wTAO/vTAO/TwTAO 封装体的定性均是变量。
5. **竞争挤压**：Fetch+AGIX+OCEAN 合并后 agent 叙事集中到 ASI；RENDER BME 直接销毁、AKT 部署抽成的价值捕获路径比 TAO 更短更硬。
6. **社区裂痕**：2026-04 Covenant AI 退出事件砸盘 37,000 TAO（~$10M），引发 −18%~−27% 下跌与 Steeves 中心化争议；Conviction Upgrade 虽加了 timelock，但治理信任已受损。
7. **补贴悬崖**：inference subnet emission-to-revenue 比高达 22:1–40:1，halving 后补贴减半，中小 subnet 经济模型可能坍塌，128 slots 的淘汰机制会加速出清。
8. **无直接收入**：协议层不收 gas/不抽成，$3.4B MC 对应可验证协议收入 ≈ $0，P-S 模型无法自洽，估值完全依赖叙事与稀缺性。

## 五、投资逻辑一句话总结

**多头 3 条**：
1. Fair launch、无 VC 份额、21M 硬顶、减半节奏对标 BTC——机构能讲的"数字商品"稀缺故事在 AI 赛道里最干净。
2. 128 个注册 subnet、89 个 live，Targon/SCORE/Vanta 已跑出 $10M+ 真实 ARR，是少数在生产环境跑通的开放 AI 协调层。
3. GTAO S-1 + Polychain $200M + Coinbase 上线构成的机构化管线，进度领先所有其他 AI 代币。

**空头 3 条**：
1. 协议零抽成、P-S >1,000x，对比 RENDER/AKT 的直接销毁/池税，价值捕获路径最弱。
2. PoA + sudo key + subnet owner 质押集中，与"去中心化 AI"叙事自相矛盾。
3. FDV $6.4B 赛道第一、回撤仅 −61%（同业 −89%~−97.5%），意味着 TAO 已经在交易"机构化溢价"，一旦 GTAO 延迟或 AI 退潮，杀估值空间大于同业。
