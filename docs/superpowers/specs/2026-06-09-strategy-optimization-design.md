# 策略参数优化模块设计

> **创建日期**: 2026-06-09
> **状态**: 待审核

---

## 1. 概述

### 1.1 目标

创建参数优化脚本，通过网格搜索找到最佳策略参数组合。

### 1.2 背景

当前回测参数（调仓频率、选币比例）为硬编码，需要自动化寻优。

### 1.3 范围

- 网格搜索调仓周期和选币比例
- 输出多维度结果表格
- 生成 HTML 报告

---

## 2. 详细设计

### 2.1 参数网格

```python
REBALANCE_PERIODS = [3, 5, 7, 10, 14]  # 调仓周期（天）
TOP_PERCENTAGES = [0.10, 0.20, 0.30]   # 选币比例
# 总组合数: 5 × 3 = 15 种
```

### 2.2 数据加载

从 `data/factors/` 读取因子评分，从 `data/raw/coingecko/` 读取价格数据。

### 2.3 网格搜索

遍历所有参数组合，调用 SimpleBacktester 运行回测，收集指标。

### 2.4 HTML 报告

表格列：调仓周期、选币比例、夏普比率、最大回撤、总收益、年化收益、胜率、交易次数。

按夏普比率降序排列，最佳参数高亮。

### 2.5 命令行参数

`--start`, `--end`, `--fee`, `--output`, `--periods`, `--top-pcts`

---

## 3. 实现方案

独立脚本 `scripts/analysis/optimize_strategy.py`，调用现有 SimpleBacktester。

---

## 4. 测试计划

网格搜索遍历、结果排序、报告生成、数据加载、手续费计入。
