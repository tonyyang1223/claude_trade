## 七、自动化评分系统设计

### 7.1 自动评分规则示例

```python
# 市值排名评分
def score_market_cap_rank(rank):
    if rank <= 10:
        return 5
    elif rank <= 50:
        return 4
    elif rank <= 100:
        return 3
    elif rank <= 200:
        return 2
    else:
        return 1

# 供应量评分（限量更优）
def score_supply(max_supply, circulating_supply):
    if max_supply is None:
        return 3  # 无限量
    ratio = circulating_supply / max_supply
    if ratio > 0.8:
        return 5  # 大部分已流通
    elif ratio > 0.5:
        return 4
    else:
        return 2  # 大量未解锁，有抛压风险

# RSI评分
def score_rsi(rsi):
    if rsi < 30:
        return 5  # 超卖，买入机会
    elif rsi < 40:
        return 4
    elif rsi <= 60:
        return 3  # 中性
    elif rsi <= 70:
        return 2
    else:
        return 1  # 超买，谨慎
```

### 7.2 综合评分公式

```
总分 = Σ(维度得分 × 权重)

建议权重分配：
- 市场数据类：20%
- 技术指标类：15%
- 链上分析类：20%
- 情绪分析类：10%
- 社交媒体类：10%
- 项目信息类：15%
- 人工评估类：10%
```
