核心结论

0x Protocol (ZRX) 是以太坊老牌 DEX 协议，价格 ~$0.12，市值 ~$100M，流通 848M / 最大 1B。老牌协议 + Swap API 基础设施 + 较 ATH −95% + 85% 流通 是多头逻辑，Uniswap 碾压 + 排名 #262 + 长期下跌 + 代币与业务脱钩 是主要空头因素。

核心判断：ZRX 是 DEX 赛道的「老牌但边缘化」选手——2017 年创立，2021 年牛市高点 $2.5，如今跌至 $0.12（−95%）。Swap API 仍被钱包集成，但代币价值捕获弱，业务收入与 ZRX 持有者关联度低。属于「基础设施好但代币不行」的典型案例。适合 DEX 赛道深度逆向投资者，需关注协议费用分成机制改革。
