核心结论

PROM 是老牌数据 DeFi 项目（2017 年创立），2021 年牛市高点 $106，如今跌至 ~$5（−95%）。近期转型为 Prom Network，主打 Web3 Agent 经济（链上身份/银行/市场）。95% 全流通 + 深度回调 + Agent 新叙事 是多头逻辑，原数据叙事失败 + Agent 转型未验证 + 排名靠后 是主要空头因素。

核心判断：这是典型「老牌项目二次创业」——原数据货币化叙事已死，转型 Agent 经济尚未看到 TVL/用户数据。95% 全流通是唯一硬利好（无抛压），但 18.3M 的小供应意味着流动性和市值弹性都依赖叙事驱动。适合逆向题材投资者小仓位埋伏 Agent 经济叙事，不适合重仓。

⚠️ 本报告基于公开数据整理，不构成投资建议；PROM 数据源分歧较大，加密货币波动剧烈，据此操作风险自担。
