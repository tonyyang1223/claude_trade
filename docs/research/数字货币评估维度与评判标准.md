# 数字货币评估维度与评判标准

> 基于课程《数字货币投资研究》总结整理

## 一、市场周期与时机判断

### 1.1 市场周期阶段识别

| 阶段 | 特征 | 操作建议 |
|------|------|----------|
| **智能资金期** | 无人关注、价格横盘、媒体无报道 | ✅ 最佳买入时机 |
| **起飞期** | 价格开始上涨、早期投资者进入 | 可考虑入场 |
| **熊陷阱** | 首次回调、恐慌性抛售 | 保持持有，不要恐慌 |
| **媒体关注期** | 开始出现在新闻中、讨论增加 | 谨慎追高 |
| **贪婪期/峰值** | 街边小店都在讨论、FOMO情绪高涨 | ⚠️ 卖出信号 |
| **熊市** | 价格大幅下跌、恐慌蔓延 | 等待底部收集 |

### 1.2 牛熊市判断标准

- **牛市定义**：从某时间点到另一时间点，价格上涨 ≥20%
- **熊市定义**：从峰值下跌 ≥20% 并持续下跌

### 1.3 最佳/最差买入时机

**最佳时机：**
- 市场无人关注时
- 价格处于支撑位附近
- 成交量开始增加但价格未大幅上涨
- 项目有实际进展但未被市场发现

**最差时机：**
- 币种被大量炒作后（Pump阶段）
- 社交媒体疯狂讨论时
- 价格已经大幅上涨（如5x-50x后）
- 纯粹因为名人推文而上涨的币种

## 二、比特币主导地位与资金流向

### 2.1 比特币主导地位分析

```
比特币主导地位 = 比特币市值 / 加密货币总市值
```

| 主导地位 | 市场状态 | 操作建议 |
|----------|----------|----------|
| > 50% 且上升 | 资金流向比特币 | 持有比特币 |
| < 50% 且下降 | 山寨币季节 | 转向山寨币 |
| 历史低点 ~30% | 极端山寨币季节 | 警惕回调风险 |

### 2.2 资金流向规律

```
法币 → 比特币 → 高市值山寨币 → 中市值山寨币 → 低市值山寨币
                                                    ↓
                              法币 ← 比特币 ← 山寨币（风险规避时回流）
```

### 2.3 判断工具

- **Coin360**：查看各币种主导地位
- **Blockchaincenter**：判断比特币/山寨币季节
- **TradingView**：BTC.D（比特币主导地位图表）

## 四、代币经济学评估

### 4.1 代币指标评估

| # | 评估维度 | 关键问题 | 理想标准 |
|---|----------|----------|----------|
| 36 | 代币用途 | 代币在生态中有什么作用？ | 必须有实际用途 |
| 37 | 市值排名 | 当前排名多少？ | 前100名外机会更大 |
| 38 | 流通量 | 已流通比例多少？ | 关注解锁压力 |
| 39 | 交易量 | 日交易量如何？ | 交易量/市值比率分析 |
| 40 | 供应量 | 是否有限量供应？ | ✅ 限量供应更优 |
| 41 | 质押率 | 有多少代币被质押？ | 高质押率表示信心 |
| 42 | ICO表现 | ICO时的需求如何？ | 参考历史数据 |
| 43 | 钱包支持 | 主流钱包是否支持？ | 基础设施完善度 |
| 44 | 法律合规 | 是否有法律风险？ | 避免诉讼风险 |

### 4.2 关键指标解读

**市值/交易量比率：**
- 交易量增加但市值未大幅上涨 → 可能正在收集（买入信号）
- 交易量增加伴随市值大幅上涨 → 可能正在分发（警惕）

**通胀 vs 通缩：**
- 通缩代币（限量供应）长期更优
- 关注代币解锁时间表

### 5.1 核心链上指标

| 指标 | 含义 | 使用场景 |
|------|------|----------|
| **NUPL** | 未实现净利润/亏损比 | 判断市场情绪 |

## 六、技术分析要点

### 6.1 核心技术指标

| 指标 | 用途 |
|------|------|
| **支撑/阻力位** | 判断价格关键位置 |
| **趋势通道** | 判断价格走势方向 |
| **RSI** | 判断超买超卖 |
| **移动平均线** | 50日/200日均线判断趋势 |
| **斐波那契回撤** | 判断回调位置 |

### 6.2 技术分析注意事项

1. **整数规则**：避免在整数位设置订单（如$31），使用小数位（如$30.90）
2. **深度分析**：查看买卖盘深度，判断支撑/阻力强度
3. **止损纪律**：每笔交易都应设置止损
4. **宏观关联**：关注DXY（美元指数）、黄金、通胀数据

### 6.3 成交量分析

- 成交量增加 + 价格横盘 = 收集阶段（买入信号）
- 成交量增加 + 价格上涨 = 可能继续上涨
- 成交量减少 + 价格上涨 = 上涨动力不足

## 八、风险管理

### 8.1 投资组合配置

| 市值类型 | 风险等级 | 建议配置 |
|----------|----------|----------|
| 高市值（>$100亿） | 低风险、低回报 | 50% |
| 中市值（$2.5-100亿） | 中等风险、中等回报 | 30% |
| 低市值（<$2.5亿） | 高风险、高回报 | 20% |

### 8.2 风险控制原则

1. **不要投入超过你能承受损失的资金**
2. **设置止损单**：每笔交易都应有退出计划
3. **避免杠杆交易**：加密货币本身波动已足够大
4. **警惕FOMO和FUD**：保持理性，不被情绪左右
5. **分散投资**：不要把所有资金投入单一币种

### 8.3 心理陷阱

| 陷阱 | 表现 | 应对 |
|------|------|------|
| **FOMO** | 害怕错过上涨而追高 | 坚持策略，不追高 |
| **FUD** | 因恐慌而低价抛售 | 关注基本面，不被噪音影响 |
| **贪婪** | 想赚更多而不止盈 | 设定目标，及时止盈 |

## 九、投资策略框架

### 9.1 80/20策略

- **80% HODL**：长期持有看好的项目
- **20% 交易**：利用技术分析进行短期交易

### 9.2 研究流程

```
1. 链上分析（判断比特币状态）
      ↓
2. 基本面分析（筛选优质项目）
      ↓
3. 技术分析（确定入场时机）
      ↓
4. 执行交易 + 风险管理
```

### 9.3 项目对比评估方法

1. 选择同赛道的2-3个项目
2. 使用评估清单逐一打分
3. 计算加权总分
4. 选择得分最高的项目投资

## 十、被动收入方式

### 10.1 Staking（质押）

| 类型 | 特点 | 收益率 |
|------|------|--------|
| 锁定质押 | 锁定一定期限，收益较高 | 较高 |
| 灵活质押 | 随时可取，收益较低 | 较低 |
| DeFi质押 | 在DeFi平台质押 | 波动较大 |

### 10.2 Yield Farming（流动性挖矿）

- 提供流动性赚取交易费和代币奖励
- 注意无常损失风险

### 10.3 储蓄产品

| 类型 | 特点 |
|------|------|
| 灵活储蓄 | 随时可取，类似活期 |
| 锁定储蓄 | 锁定期限，收益更高 |
