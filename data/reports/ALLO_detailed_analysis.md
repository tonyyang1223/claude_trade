## 一、项目概况

### 1.1 基本信息

| 项目 | 详情 |
|------|------|
| **名称** | Allora Network |
| **代币符号** | ALLO |
| **CoinGecko ID** | allora |

| **区块链** | Cosmos-based + 多链跨链 (LayerZero OFT) |
| **合约地址** | Ethereum: 0x8408D45b61f5823298F19a09B53b7339c0280489 |

### 1.2 项目定位

**Allora 是一个自我改进的去中心化 AI 网络 (Self-Improving, Decentralized Machine Intelligence Network)**

核心创新：
- **模型协调网络 (MCN)**: 整合数千个机器学习模型，通过集体智能生成比单一模型更准确的预测
- **上下文感知机制**: 网络能够预测参与者在当前条件下的表现，动态调整权重
- **差异化激励结构**: 根据参与者对网络目标的独特贡献进行奖励，避免无效激励

### 1.3 应用场景

| 场景 | 具体应用 |
|------|----------|
| **DeFi** | 价格预测、波动性警报、风险评估、交易策略优化 |
| **AI Agent** | 为 NEAR、Virtuals、Cod3x 等 AI Agent 生态提供智能决策支持 |
| **自主系统** | 在动态、高维环境中做出一致性响应 |
| **数据市场** | 隐私安全的训练数据基础设施 |

### 1.4 代币效用

| 用途 | 说明 |
|------|------|
| **购买推理服务** | 使用 Pay-What-You-Want (PWYW) 模型购买网络预测结果 |
| **质押奖励** | Reputer 和 Network Validator 质押获得奖励 |
| **委托质押** | 普通用户可委托给验证者获得收益 |
| **创建主题** | 支付 ALLO 创建新的预测主题 |
| **工作节点注册** | Worker 和 Reputer 注册费用 |
| **网络奖励** | 网络用 ALLO 支付参与者奖励 |
